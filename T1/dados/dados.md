# Casos de Teste

## Teste 1 — Movimento direto

Origem: `a1`
Destino: `c2`

Objetivo: verificar um caso em que o destino pode ser alcançado em apenas um movimento.

Entrada:
```
a1 c2
```

Saída:
```
To get from a1 to c2 takes 1 knight moves.
```

## Teste 2 — Distância maior

Origem: `a1`
Destino: `h8`

Objetivo: verificar a busca para uma distância maior.

Entrada:
```
a1 h8
```

Saída:
```
To get from a1 to h8 takes 6 knight moves.
```
